# Snor

Snor is a private, cross-platform AI chat client that runs language models locally on your Android device. When a model isn't loaded, it falls back to cloud APIs (OpenAI, Anthropic, Gemini, Kimi, and more).

This repo hosts the static landing page and points to the Android APK release.

## Files

- `index.html` / `styles.css` / `script.js` — landing page
- `assets/` — favicon and Open Graph image

## Download

- Android APK (v1.0.3, ~101 MB): https://github.com/ravvdevv/snor-landing/releases/latest/download/snor-v1.0.3.apk
- Sideload it on any Android 8.0+ ARM64 device (allow "install from unknown sources" when prompted).
- Live site: https://snor-landing.vercel.app/
