# Snor

Snor is a private, cross-platform AI chat client that runs language models locally on your Android device. When a model isn't loaded, it falls back to cloud APIs (OpenAI, Anthropic, Gemini, Kimi, and more).

This repo hosts the static landing page and serves the Android APK.

## Files

- `index.html` / `styles.css` / `script.js` — landing page
- `downloads/snor-v1.0.3.apk` — latest Android release (~140 MB)
- `assets/` — favicon and Open Graph image

## Demo

- Web demo: https://ai-chat-orailnoor.web.app/
- Android: download `snor-v1.0.3.apk` and sideload (Android 8.0+, ARM64)
