# Snor

**Private, cross-platform AI chat client for Android.**

Run language models locally on your device, with cloud API fallback when no local model is loaded. Supports OpenAI, Anthropic, Gemini, Kimi, and more.

</div>

## Files

* `index.html` / `styles.css` / `script.js` — landing page
* `assets/` — app icon and Open Graph image

## Download

* **Android APK (v1.0.3, ~101 MB):** https://github.com/ravvdevv/snor-landing/releases/latest/download/snor-v1.0.3.apk
* Sideload it on any **Android 8.0+ ARM64** device.
* Enable **"Install from unknown sources"** when prompted.
* **Live site:** https://snor-landing.vercel.app/
